# keysso-cli — подключите AI к данным Keys.so

`keysso-cli` нужен, если вы хотите, чтобы нейросеть не «придумывала» маркетинг, а принимала решения на реальных данных конкурентов из Keys.so

С ним AI-агент:
- находит ваших реальных PPC-конкурентов
- собирает ключи и креативы из контекста
- показывает динамику рекламы и видимость
- превращает это в конкретные гипотезы для запуска


## Почему это важно для AI

Без skills нейросеть дает общие советы.

Со skills и `keysso-cli` нейросеть:
- знает точные команды для сбора данных
- понимает структуру ответов API
- работает по повторяемому workflow, а не «по вдохновению»

Именно поэтому ключевой шаг не просто установить CLI, а установить skills. 


## Установка за 2 минуты

Для работы необходим персональный ключ (токен). Токен можно сформировать в настройках [личного кабинета](https://www.keys.so/ru/panel?p=8462) в блоке API.

```sh
git clone https://github.com/tjvjk/keysso-cli.git
cd keysso-cli
uv tool install --editable .
export KEYSSO_API_KEY="ваш-токен"
keysso-cli install --skills
```

После этого набор skills будет создан в `.claude/skills/keysso-cli`


## Описание команд

### Дашборд

- `keysso-cli dashboard domain --domain <домен>` # сводка по домену
- `keysso-cli dashboard keyword --keyword <фраза>` # сводка по ключевой фразе
- `keysso-cli dashboard ad-history --domain <домен>` # история рекламных метрик домена
- `keysso-cli dashboard similarkeys --keyword <фраза>` # дополняющие фразы
- `keysso-cli dashboard top-visibility --domain <домен>` # рейтинг сайтов по видимости

### Контекстная реклама

- `keysso-cli context concurents --domain <домен>` # конкуренты домена в контекстной рекламе
- `keysso-cli context keywords list --domain <домен>` # ключевые слова домена в контекстной рекламе
- `keysso-cli context keywords byads --domain <домен> --ads-id <id>` # ключевые слова конкретного объявления
- `keysso-cli context ads retrieve --domain <домен>` # объявления домена
- `keysso-cli context ads links --domain <домен>` # уникальные ссылки из объявлений
- `keysso-cli context ads facts --domain <домен>` # уникальные факты из объявлений

### Яндекс Директ

- `keysso-cli direct domain --domain <домен>` # объявления Яндекс Директ по домену
- `keysso-cli direct ads --kid <id>` # объявления Яндекс Директ по идентификатору фразы
- `keysso-cli direct ads --keyword <фраза>` # объявления Яндекс Директ по поисковой фразе
